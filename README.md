# EligibleMe — Placement Eligibility Platform

A web application that helps students check job eligibility, compare their skills with job requirements, and prepare for placement opportunities.

## Live Demo

**[Open EligibleMe](https://eligibleme-placement-platform.vercel.app)**

## Features

- Job eligibility checking
- Skills and job requirement matching
- Student profile management
- Placement readiness dashboard

## Technology Stack

React, TypeScript, Vite, and CSS.

## Run Locally

```bash
npm install
npm run dev
```
